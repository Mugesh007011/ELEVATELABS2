Customer Personality Analysis Dashboard

This project analyzes customer demographics, income, spending behavior, and campaign responses using Power BI/Tableau. Various visualizations were created to identify customer trends, purchasing patterns, and marketing effectiveness.

Tools Used

- Power BI / Tableau
- Customer Personality Analysis Dataset

Key Insights

- Middle-income customers form the largest group.
- Customers aged 30–50 spend the most.
- Married customers make more purchases.
- Wine and meat products are top-selling categories.
- Campaign acceptance rate is low.

Conclusion

The dashboard provides valuable insights that help businesses improve marketing strategies and customer engagement.
